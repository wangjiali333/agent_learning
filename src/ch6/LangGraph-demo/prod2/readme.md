从零构建一个完整的 智能研究助手（Smart Research Assistant）。这个助手能搜索信息、分析文档、生成报告，并支持多轮对话

需求描述:

用户输入问题
    ↓
[问题分类] → 是简单问题？→ 直接回答
    ↓ 否
[研究流程]
    ├── 搜索相关信息（工具调用）
    ├── 检索本地知识库（RAG）
    ├── 综合分析（LLM 推理）
    └── 生成结构化报告（输出解析）
    ↓
[质量审查] → 不通过？→ 补充研究（循环）
    ↓ 通过
[输出结果] → 支持追问（多轮对话 + 记忆）

涉及到的知识:
 - 文档加载，向量检索(RAG)
 - 对话记忆管理
 - 自定义工具(搜索，文件读写)
 - ReAct Agent范式
 - LangGraph工作流，持久化
 - 多Agent协作

技术小结:
LangGraph：定义复杂的工作流图，支持条件路由、循环、持久化
自定义工具：搜索、知识库检索、文件保存
RAG：本地知识库的向量检索
LCEL 管道：prompt | llm | parser 链式调用
Prompt 工程：针对不同角色的系统提示
输出解析：Pydantic 结构化输出
状态管理：自定义 State 在节点间传递数据
质量审查循环：确保输出质量
