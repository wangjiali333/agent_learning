# LangChain 知识文档
## 一、概述
LangChain 是一个用于构建大语言模型（LLM）应用程序的开发框架。它的核心目标是让开发者能够以最简单的方式开始构建 LLM 应用，同时保持足够的灵活性和生产就绪能力。

LangChain 最初由两个主要组件构成：LLM 抽象层和链（Chains）——即为常见用例预定义的计算步骤序列。随着生态的发展，LangChain 已扩展为一个完整的框架体系，支持从简单的提示工程到复杂的多智能体系统的构建。

## 二、架构
LangChain 作为一个框架由多个包组成：

### 2.1 langchain-core
该包包含不同组件的基本抽象以及将它们组合在一起的方法。核心组件的接口——如大语言模型、向量存储、检索器等——在此定义，不包含任何第三方集成，依赖项保持非常轻量级。

### 2.2 langchain
主要的 langchain 包包含链、代理和检索策略，这些构成了应用程序的认知架构。这里的所有链、代理和检索策略不特定于任何一个集成，而是适用于所有集成的通用策略。

### 2.3 langchain-community
此包包含由 LangChain 社区维护的第三方集成。包含了各种组件（大语言模型、向量存储、检索器）的所有集成，所有依赖项均为可选，以保持包的轻量化。

### 2.4 合作伙伴包
流行的集成被拆分到各自的包中，如 langchain-openai、langchain-anthropic 等，以改善对这些重要集成的支持。

## 三、核心组件
LangChain 将组件组织为以下主要类别：

### 3.1 模型（Models）
模型组件提供 AI 推理与生成能力，包括聊天模型、大语言模型（LLM）和嵌入模型。它们分别用于文本生成与推理、语义理解等场景。

### 3.2 工具（Tools）
工具扩展了智能体的能力，使其能够获取实时数据、执行代码、查询外部数据库以及在现实世界中采取行动。工具可以是通用工具（如搜索）、其他链，甚至是其他智能体。

最简单的工具创建方式是从 langchain 包中导入 tool 函数。LangChain 还提供了工具包（Toolkits）的概念，将设计为协同使用的工具分组在一起。
